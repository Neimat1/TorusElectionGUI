Torus Election Visualizer

A Quarkus web application for visualizing leader election in a two-dimensional torus network with a plain HTML/CSS interface, JSON API, canvas animation, and SOLID service-layer architecture.

Run the web app Read architecture

What It Does

Configurable Torus

Choose rows and columns, then enter unique process IDs for each grid cell.

Leader Election API

The browser posts input to /api/election; Quarkus runs the torus election and returns JSON.

Canvas Visualization

The plain JavaScript UI renders final state and replays message propagation using the returned animation steps.

Run

Development Server

mvn quarkus:dev

Open The App

http://localhost:8080

Package And Run

mvn package
java -jar target/quarkus-app/quarkus-run.jar
