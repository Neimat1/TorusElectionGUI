Running the Repository

This project is a Java 17 Quarkus web application built with Maven. The UI is served from src/main/resources/META-INF/resources, and the election API is exposed by Quarkus.

Prerequisites

  • JDK 17 or later
  • Maven 3.8 or later
  • Internet access on the first build so Maven can download Quarkus and test dependencies

Run In Development

mvn quarkus:dev

Open the app at http://localhost:8080.

Build And Run The Packaged App

mvn package
java -jar target/quarkus-app/quarkus-run.jar

Useful Routes

  • /index.html: interactive visualizer
  • /api/election: JSON election endpoint
  • /docs/index.html: documentation home

IDE Notes
