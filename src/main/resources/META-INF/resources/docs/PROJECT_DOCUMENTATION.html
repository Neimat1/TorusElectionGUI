Project Documentation

Torus Election Visualizer is a Quarkus web application that demonstrates leader election on a two-dimensional torus topology. The browser UI sends election input to a REST resource, and the backend returns final node state, metrics, logs, and animation steps.

Current Package Shape

PackageResponsibility
resourceHTTP endpoints and request/response boundary.
validationInput validation before domain execution.
mapperMapping domain state and algorithm output into API response records.
serviceInterfaces for orchestration, network creation, and election execution.
service.implQuarkus beans and torus-specific implementations.
modelDomain objects and transport records shared across layers.
META-INF/resourcesPlain HTML, CSS, JavaScript, icons, and documentation assets.

Runtime Flow

  1. The browser reads rows, columns, and process IDs from the form.
  2. app.js posts JSON to /api/election.
  3. ElectionResource delegates to ElectionService.
  4. TorusElectionService validates input, creates the network, creates the algorithm, runs election, and maps the result.
  5. The browser draws the returned nodes and animation steps on canvas.
